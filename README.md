# 👋 Hello from Team Nexus!

Welcome to our official GitHub organization for our **1st-Year 2nd-Semester University Project**. We are a team of passionate software engineering students building practical desktop and database-driven applications.

---

### 🚀 Featured Project: Rent-A-Tool
Our primary project this semester is **Rent-A-Tool**, a comprehensive desktop application designed to streamline hardware and equipment rental management. 

* **Purpose:** Built for local tool rental shops to manage inventory, customer rentals, billing, and user accounts efficiently.
* **Architecture:** Developed using **C++/CLI** and **Windows Forms** for a robust desktop interface, backed by a **MySQL Database** for secure and persistent data storage.

---

### 🛠️ Tech Stack & Tools
* **Programming Language:** C++ (.NET Framework / C++/CLI)
* **UI Framework:** Windows Forms
* **Database:** MySQL (Connector/NET)
* **Security:** Salted SHA-256 Password Hashing built into .NET
* **Version Control:** Git & GitHub

---

### 👥 System Features
* **Secure Authentication:** Role-based access control supporting **Admin** and **Cashier** accounts with encrypted passwords.
* **Inventory & Rental Management:** Track available tools, rental durations, and pricing.
* **User-Friendly Dashboard:** Clean and intuitive Windows Forms navigation for daily shop operations.
